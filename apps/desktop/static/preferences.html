Assistant

Lets an AI assistant you run on this PC ask Exxeed about the race — fuel, gaps, weather, standings — over MCP. Exxeed never calls a model itself, and nothing leaves this machine unless your assistant sends it.
Off
Off, it can only read. On, it can also do what the importer and the tracer do: find a track guide, write callouts from its transcript and import them as a draft, and read a reference lap off the guide's video — which, saved, replaces the one you have (the old lap is kept).
Add Exxeed to your assistant as an MCP server over HTTP at that address, with the header Authorization: Bearer <token>. The token is the only thing stopping other programs on this PC asking too, so treat it like a password. New token cuts off every assistant set up with the old one.
