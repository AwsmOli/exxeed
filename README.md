# Exxeed

Sim racing overlays — for streams, recordings, or races — as a service other sim racers could use.

> Status: early idea, not fleshed out yet.

## Concept

Working title: **Exxeed**. The idea is to offer sim racing broadcast overlays (lap times, standings, sector splits, and similar live data) as a service, the same kind of thing built one-off for the [Live Timing Dashboard](https://github.com/AwsmOli/Live-Timing-Dashboard) project (NLS Live Timing), but generalized so other sim racers and leagues could use it too.

Still just a headline — no design or code yet.
